
# Ready2Play (R2P) Web App - Prototipo Python

Questo archivio contiene il prototipo della web app Ready2Play basato sulla documentazione dell'ITT Enrico Fermi.

## Requisiti
Per eseguire l'app è necessario avere Python installato e la libreria `streamlit`.

## Installazione
1. Estrai il contenuto del file ZIP.
2. Apri il terminale nella cartella estratta.
3. Installa Streamlit (se non lo hai già):
   `pip install streamlit`

## Esecuzione
Lancia l'applicazione con il comando:
`streamlit run app.py`

## Funzionalità Incluse
- **Dashboard**: Visualizzazione campi consigliati (Slide 12).
- **Ricerca**: Filtri e risultati (Slide 13).
- **Smart Access**: Simulazione sblocco IoT e risparmio energetico (Documentazione Sez. 2).
- **Chat**: Interfaccia per l'organizzazione tra utenti (Slide 15).
